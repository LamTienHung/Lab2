# Project Rules - Lab 02

## Coding Standards
- Use const and let instead of var.
- Use ES Modules with import and export.
- Avoid inline HTML event handlers.
- Never inject untrusted content using innerHTML.
- Use semantic HTML elements.
- Use textContent or createTextNode for text.
- Keep functions small and testable.

## Development Workflow
1. Define the functional requirement.
2. Implement one function at a time.
3. Test each function independently.
4. Verify the DOM using browser DevTools.
5. Commit completed milestones to Git.

## Security
- Avoid unsafe HTML injection.
- Validate VNode structures.
- Use safe DOM APIs.
